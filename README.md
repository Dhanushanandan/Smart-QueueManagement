## 📌 Overview
The **Smart Queue Management System** is an AI-powered solution designed to eliminate physical queues and optimize appointment booking for government services such as **NIC, Passport, and Driving License**.

---

## 🎯 Features

### 👤 User
- Secure Login & Registration (OTP)
- Upload Documents
- AI OCR Extraction
- Appointment Booking
- Smart Time Slot Suggestions
- Token Generation

### 🏢 Admin
- Manage Users & Services
- Manage Appointments
- View Reports

### 🧑‍💼 Teller
- View Queue
- Call Tokens
- Update Status

---

## 🤖 AI Features
- OCR Data Extraction
- Document Type Detection
- Smart Scheduling Algorithm

## ⚙️ Setup

```bash
git clone https://github.com/your-repo.git
cd project
```

### Frontend
```bash
cd frontend
npm install
npx expo start
```

### Backend
```bash
cd backend
npm install
npm start
```

### AI Service
```bash
cd ai-service
python app.py
```
